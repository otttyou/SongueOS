# SoengOS v2 — React desktop contract

This sitting extracts the HTML prototype (`SoengOS.html`) into a window manager with Song materials.

## Identity

- Name: **SoengOS** / **宋** (Jyutping of 宋, Portuguese-smooth spelling)
- Default chrome: **hybrid** (menu bar + dock + Linux taskbar)
- Protocol: `soeng://`
- Shell: `soeng-sh` (`user@soeng`)
- Persist key: `soeng-os` (theme, wallpaper, dock magnification, desktop mode, notes)

## Modes

| `desktopMode` | Menu bar | Dock | Taskbar |
| --- | --- | --- | --- |
| `hybrid` | yes | yes | yes |
| `mac` | yes | yes | hidden |
| `linux` | hidden* | hidden* | yes |

\*On a narrow phone the dock and menu bar stay so apps remain reachable.

Switch from Settings, Control Center, Spotlight (`hybrid`/`mac`/`linux`), or:

```
user@soeng:~$ mode linux
```
