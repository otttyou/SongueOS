About SoengOS

SoengOS is a web-enabled Linux desktop contract. The Fable sitting is a paper studio: warm wall, espresso ink, and the same quiet motion as a Kengo wall — Fable, Cool S, portraits — not a black terminal room.

Built as a single-file browser prototype using vanilla JavaScript and CSS. All applications run entirely within the browser. No external dependencies, no frameworks, no runtime.
